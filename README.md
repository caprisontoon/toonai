# TOONAI — AI 대화형 후원 서비스

투네이션 도네이터(후원) 서비스를, **폼(form) 입력 방식**에서 **AI 채팅 대화형 방식**으로
업그레이드하기 위한 기획 + 디자인 패키지입니다.

> "후원은 '결제'가 아니라 '마음의 표현'이다.
> 폼을 대화로 바꾸면, 후원 완료율과 객단가가 동시에 오른다."

## 🎯 한눈에 보기

기존 투네이션 후원은 **닉네임 → 금액 → 효과 → 메시지 → 결제**를 순서대로 채워야 하는
긴 폼입니다. 빈 메시지 칸 앞에서 멈추고("뭐라고 쓰지?"), 금액을 못 정하고, 옵션이 많아
이탈합니다. TOONAI는 이 과정을 **AI 후원 도우미 '투니(Tooni)'** 와의 짧은 대화로 바꿉니다.

```
투니: 하나비 스트리머에게 어떤 마음을 전하고 싶으세요?
     [🎉 축하해요] [💪 응원해요] [😂 고마워요] [✍️ 직접 쓸래요]
나  : 🎉 축하해요
투니: 10만 구독 축하군요! 딱 맞는 금액과 불꽃놀이 효과를 추천할게요 🎆
 ...  (금액 · 효과 · 메시지를 AI가 거들어 30초 만에 완료)
```

## 👥 역할별 산출물 (3인 협업 결과물)

| 역할 | 담당 | 산출물 |
|------|------|--------|
| **사업기획자** | 후원 매출을 올리는 전략 정의, 서비스팀에 요구사항 전달 | [`docs/01_사업기획.md`](docs/01_사업기획.md) |
| **서비스 기획자** | 사업 요구사항 기반 AI 대화형 후원 서비스/UX 설계 | [`docs/02_서비스기획.md`](docs/02_서비스기획.md) |
| **디자이너** | 기획을 직관적 UI로 디자인 (가이드 + 프로토타입) | [`docs/03_디자인.md`](docs/03_디자인.md) |

### 2차 — 엑셀(크루) 후원 특화 페이지 🏆

엑셀 방송(합방 실시간 후원 순위전)은 후원 매출의 절대 비중. **"순위판이 곧 후원 버튼"**
이 되는 크루 엑셀 모드 도네이터 페이지를 설계했다.

| 역할 | 담당 | 산출물 |
|------|------|--------|
| **사업기획자** | 엑셀 방송 모니터링 체계 + 매출 전략(격차=객단가) | [`docs/04_엑셀후원_사업기획.md`](docs/04_엑셀후원_사업기획.md) |
| **서비스 기획자** | 실시간 순위판·역전 버튼·마감 드라마·가드레일 설계 | [`docs/05_엑셀후원_서비스기획.md`](docs/05_엑셀후원_서비스기획.md) |
| **디자이너** | 스코어보드 UI 가이드 + 동작 프로토타입 | [`docs/06_엑셀후원_디자인.md`](docs/06_엑셀후원_디자인.md) |

> 핵심 기능: 실시간 순위판(행 탭=후원) · **⚡ 역전 버튼**(격차+₩1,000 자동 계산) ·
> 격차 게이지 · 마감 타이머/스나이핑 타임 · 서포터 랭킹 · 투니 추월 알림 ·
> 일일 한도 가드레일(완화 모드)

## 🖥️ 프로토타입 실행

설치 불필요한 단일 HTML 파일 2종입니다.

| 파일 | 내용 |
|------|------|
| `prototype/index.html` | **AI 대화형 후원** — 투니와 대화하며 30초 후원 |
| `prototype/excel.html` | **크루 엑셀 후원** — 2분 데모 라운드, 경쟁 팬덤 자동 시뮬레이션, 역전/스나이핑 체험 |

```bash
# 방법 1: 그냥 파일 열기
open prototype/excel.html      # macOS
xdg-open prototype/excel.html  # Linux

# 방법 2: 로컬 서버
cd prototype && python3 -m http.server 8080
# → http://localhost:8080  /  http://localhost:8080/excel.html
```

데스크톱에서는 휴대폰 목업 안에서, 모바일에서는 전체 화면으로 보입니다.

## 📈 기대 효과 (가설)

| 지표 | 현재(폼) | 목표(AI 대화) | 핵심 동인 |
|------|---------|--------------|-----------|
| 결제 전환율(CVR) | 기준 | **+15~25%p** | 단계 축소·실시간 가이드 |
| 평균 후원액(객단가) | 기준 | **+10~20%** | 맥락 기반 금액 추천·효과 업셀 |
| 첫 후원 전환율 | 기준 | **+30%** | 신규 진입장벽 제거 |
| 메시지 작성 완료율 | 기준 | **+40%** | AI 메시지 추천(빈칸 공포 제거) |

수치는 A/B 테스트로 검증할 가설이며, 측정 설계는 [`docs/02_서비스기획.md`](docs/02_서비스기획.md) 참고.
