# TOONAI — AI 대화형 후원 서비스

투네이션 도네이터(후원) 서비스를, **폼(form) 입력 방식**에서 **AI 채팅 대화형 방식**으로
업그레이드하기 위한 기획 + 디자인 패키지입니다.

> "후원은 '결제'가 아니라 '마음의 표현'이다.
> 폼을 대화로 바꾸면, 후원 완료율과 객단가가 동시에 오른다."

## 🎯 한눈에 보기

기존 투네이션 후원은 **닉네임 → 금액 → 효과 → 메시지 → 결제**를 순서대로 채워야 하는
긴 폼입니다. 빈 메시지 칸 앞에서 멈추고("뭐라고 쓰지?"), 금액을 못 정하고, 옵션이 많아
이탈합니다. TOONAI는 이 과정을 **AI 후원 도우미 '투니(Tooni)'** 와의 짧은 대화로 바꿉니다.

```
투니: 하나비 스트리머에게 어떤 마음을 전하고 싶으세요?
     [🎉 축하해요] [💪 응원해요] [😂 고마워요] [✍️ 직접 쓸래요]
나  : 🎉 축하해요
투니: 10만 구독 축하군요! 딱 맞는 금액과 불꽃놀이 효과를 추천할게요 🎆
 ...  (금액 · 효과 · 메시지를 AI가 거들어 30초 만에 완료)
```

## 🖥️ 프로토타입 실행

클릭으로 후원 대화를 체험할 수 있는 단일 HTML 파일입니다. (설치 불필요)

```bash
# 방법 1: 그냥 파일 열기
open prototype/index.html      # macOS
xdg-open prototype/index.html  # Linux

# 방법 2: 로컬 서버
cd prototype && python3 -m http.server 8080
# → http://localhost:8080
```

데스크톱에서는 휴대폰 목업 안에서, 모바일에서는 전체 화면으로 보입니다.

## 📈 기대 효과 (가설)

| 지표 | 현재(폼) | 목표(AI 대화) | 핵심 동인 |
|------|---------|--------------|-----------|
| 결제 전환율(CVR) | 기준 | **+15~25%p** | 단계 축소·실시간 가이드 |
| 평균 후원액(객단가) | 기준 | **+10~20%** | 맥락 기반 금액 추천·효과 업셀 |
| 첫 후원 전환율 | 기준 | **+30%** | 신규 진입장벽 제거 |
| 메시지 작성 완료율 | 기준 | **+40%** | AI 메시지 추천(빈칸 공포 제거) |

수치는 A/B 테스트로 검증할 가설이며, 측정 설계는 [`docs/02_서비스기획.md`](docs/02_서비스기획.md) 참고.
