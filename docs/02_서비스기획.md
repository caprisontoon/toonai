## 1. 컨셉 — "투니(Tooni)"라는 후원 도우미

투네이션 후원의 업그레이드 버전. 시청자는 폼을 채우는 대신, **AI 후원 도우미 '투니'** 와
짧게 대화하며 후원을 완성한다. 투니는 단순 챗봇이 아니라 **후원 컨시어지**다.

- **이름/페르소나:** 투니(Tooni). 밝고 다정한 응원 친구 톤. 과하지 않게, 빠르게.
- **한 문장 정의:** *"마음을 고르면, 금액·효과·메시지·결제를 투니가 거들어 30초 만에 끝낸다."*
- **포지셔닝:** 기존 폼 = 셀프 주유 / TOONAI = 옆에서 거드는 컨시어지.

### 설계 3원칙 (사업 요구사항을 서비스 원칙으로 번역)

1. **One-Step-Ahead** — 투니는 늘 *다음 한 걸음만* 제시한다. 자유 입력보다 **탭(퀵리플라이/카드)** 우선.
2. **Never Block Payment** — AI는 결제를 절대 막지 않는다. "바로 후원" 익스프레스 항상 노출.
3. **AI Assists, Human Decides** — AI는 추천·초안까지만. 최종 금액·메시지·발송은 사람이 결정.

## 2. 정보구조 — 후원에 필요한 4개의 슬롯(Slot)

대화의 목적은 아래 4개 슬롯을 채우는 것이다. 투니는 비어 있는 슬롯을 알아서 채워 나간다.

| 슬롯 | 필수 | AI 역할 |
|------|:---:|---------|
| **받는 사람(recipient)** | ✅ | 스트리머 페이지 진입 시 자동 프리필 |
| **금액(amount)** | ✅ | 맥락·이력 기반 추천 + 앵커링 + 효과 업셀 |
| **메시지(message)** | ◻︎ | 마음/맥락 기반 초안 2~3개 톤별 추천 (핵심) |
| **효과·옵션(effect)** | ◻︎ | 마음·금액에 맞는 효과/ TTS 보이스 추천 + 라이브 미리보기 |
|  +  결제수단(payment) | ✅ | 저장수단 원탭, 캐시 부족 시 즉시 충전 결합 |

> 미로그인 사용자도 슬롯을 채울 수 있고, 결제 직전에만 인증/충전을 요구한다.

## 3. 대화 플로우 (State Machine)

투니는 7개 상태를 거치되, 슬롯이 이미 차면 **건너뛴다**. (예: 단골은 S2~S4를 점프)

```
 [S0] 인사·의도 파악 ──► [S1] 받는 사람 확인 ──► [S2] 금액 추천
        │  (마음 선택)         (보통 프리필,자동)        │ (앵커링·업셀)
        │                                               ▼
        │                                          [S3] 효과 추천 + 라이브 미리보기
        │                                               │
        │                                               ▼
        │                                          [S4] AI 메시지 초안 (핵심)
        │                                               │
        ▼                                               ▼
 [익스프레스] "바로 후원" ───────────────────────► [S5] 요약 확인
   (늘 하던대로 / 원탭)                                  │
                                                         ▼
                                                    [S6] 결제 (원탭/충전결합)
                                                         │
                                                         ▼
                                                    [S7] 완료 + 감정보상 + 재후원 루프
```

| 상태 | 목적 | 투니가 주는 것 | 사용자 행동 |
|------|------|----------------|-------------|
| **S0** 의도 | 마음을 고르게 함 | 마음 칩(축하/응원/감사/직접) | 탭 1회 |
| **S1** 대상 | 받는 사람 확정 | 자동 프리필 + 맥락 추정(예:10만 달성) | 확인 |
| **S2** 금액 | 객단가↑ | 금액 카드(인기 표시)+효과 잠금 안내 | 탭/직접입력 |
| **S3** 효과 | 경험↑·업셀 | 마음에 맞는 효과 + **라이브 미리보기** | 탭 |
| **S4** 메시지 | 빈칸 공포 제거 | 톤별 초안 2~3개(감동/유쾌/담백) | 선택/편집 |
| **S5** 요약 | 신뢰·확인 | 요약 카드(대상·금액·효과·메시지·수단) | 확인 |
| **S6** 결제 | 마찰 0 | 원탭 결제, 캐시 부족 시 충전 결합 | 인증/결제 |
| **S7** 완료 | 감정보상·재방문 | "화면에 효과 터졌어요!" + 재후원/구독 | 다음 행동 |

### 익스프레스 경로 (Never Block Payment)
- 어느 상태에서도 상단/입력바에 **"⚡ 바로 후원"** 노출.
- 단골: S0에서 *"늘 하던대로 (₩5,000 · 박수효과)"* 칩 → 바로 S5/S6.

## 4. 핵심 기능 명세

### 4.1 AI 메시지 작성 도우미 ⭐ (최우선 차별점)
- **입력:** 선택한 마음(S0) + 맥락(달성/기념일/게임상황) + 스트리머 톤 + 후원 이력.
- **출력:** 톤별 메시지 초안 **3개** — `감동` / `유쾌` / `담백`.
- **편집:** 초안 탭 → 인라인 편집. "더 추천해줘" 재생성. "직접 쓸래요" 빈 입력.
- **가드레일:** 발송 전 모더레이션(욕설/개인정보/스팸), 스트리머 금칙어 연동, 길이 제한.

> 효과: "뭐라고 쓰지?"의 30초 정지를 제거. 메시지 작성률↑ → 스트리머 반응↑ → 재후원↑.

### 4.2 맥락 기반 금액 추천 & 업셀
- 금액 칩에 **'인기'** 앵커 1개 강조. 맥락 금액 제안(예: 10만 달성 → ₩10,000).
- 효과 잠금 안내로 자연 업셀: *"₩10,000부터 불꽃놀이 효과 🎆"*. **권유는 1회, 거절 시 중단.**

### 4.3 라이브 알림 미리보기
- 선택한 효과/메시지가 **방송 화면에 어떻게 뜨는지** 카드 안에서 애니메이션 미리보기.
- 신규의 "이게 뭐지?"를 즉시 해소(온보딩 내장), 효과 가치 체감 → 업셀 보조.

### 4.4 원탭 결제 + 충전 결합
- 저장된 결제수단 원탭(카카오페이/카드). **캐시 부족 시 '충전+후원'을 한 번에**.
- 결제 실패/취소 시 대화 맥락 유지하여 즉시 재시도.

### 4.5 후원 후 감정 보상 루프
- 완료 즉시: *"방금 하나비님 화면에 불꽃놀이가 터졌어요 🎆"* + 스트리커블 보상.
- 다음 행동 칩: **[한 번 더] [알림받기] [구독] [완료]**. 연속 후원 스트릭(gamify) 옵션.

> 진입: 시청자가 '하나비' 스트리머 후원 페이지로 들어옴 (recipient 자동 프리필).
> 맥락: 오늘 채널 구독자 10만 명 달성.

```

         어떤 마음을 전하고 싶으세요?
         [🎉 축하해요] [💪 응원해요] [😂 고마워요] [✍️ 직접 쓸래요]

         │ 받는 분   하나비                        │

         └────────────────────────────────────────┘

         따뜻한 마음 잘 전달됐어요 💜 곧 닉네임을 불러줄 거예요.
```

### 분기/예외 스크립트 (요약)
- **"직접 쓸래요"(S0):** 의도 추정 스킵 → 자유 입력 → 투니가 금액·효과만 거듦.
- **"바로 후원"(익스프레스):** S0에서 바로 요약(S5)로. 금액만 빠르게 묻고 결제.
- **금액 직접 입력:** 효과 잠금 임계값 미만이면 *"+₩○○면 불꽃놀이 가능"* 1회 안내(거절 시 진행).
- **결제 실패/캐시 부족:** "충전하고 이어서 보낼까요?" → 충전+후원 결합, 맥락 유지.
- **부적절 메시지:** 발송 전 차단 + 순화 제안 ("이 표현은 어려워요. 이렇게 바꿔볼까요?").

## 6. 사용자 스토리 (수용 기준)

- **US-1 (신규)** 처음 온 시청자로서, 용어를 몰라도 마음만 고르면 후원을 끝낼 수 있다.
  - ✅ 자유 입력 없이 탭만으로 완주 가능 / ✅ 효과는 미리보기로 이해
- **US-2 (메시지 막힘)** 무슨 말을 쓸지 모를 때, 톤별 초안에서 골라 보낼 수 있다.
  - ✅ 초안 3개 제시 / ✅ 인라인 편집 / ✅ "더 추천"
- **US-3 (단골)** 늘 하던 후원을 빠르게 반복할 수 있다.
  - ✅ "늘 하던대로" 칩 → 원탭 결제 / ✅ 어디서든 "바로 후원"
- **US-4 (객단가)** 적절한 금액을 추천받고, 원하면 더 올려 특별 효과를 쓸 수 있다.
  - ✅ '인기' 앵커 / ✅ 효과 잠금 안내(1회, 비강압)
- **US-5 (재후원)** 후원 직후 보상감을 느끼고 다음 행동으로 이어진다.
  - ✅ 효과 터짐 피드백 / ✅ [한번더][알림][구독]

## 7. 측정 설계 (A/B & 퍼널)

- **실험:** 기존 폼(Control) vs AI 대화(Variant). 트래픽 50/50, 신규/기존 세그먼트 분리.
- **1차 지표:** 결제 전환율, 평균 후원액. **2차:** 첫후원 전환, 메시지 작성률, 30일 재후원율.
- **퍼널 이벤트:** `open → intent → amount → effect → message → review → pay_success`
  각 단계 진입/이탈/소요시간 기록.
- **AI 품질:** 메시지 추천 채택률, 재생성 횟수, 모더레이션 차단율.
- **가드레일 지표(악화 시 롤백):** 평균 완료시간, 결제 실패율, CS 문의수.

## 8. 디자인팀 전달 사항 (서비스 → 디자인)

1. **모바일 우선.** 후원의 다수가 모바일/오버레이. 한 손 엄지 도달 영역에 핵심 액션.
2. **채팅 메타포.** 투니(좌)·사용자(우) 말풍선, 타이핑 인디케이터로 '대화감' 유지.
3. **인라인 카드.** 금액 선택·효과 미리보기·메시지 초안·요약·결제를 **말풍선 안 카드**로.
4. **퀵리플라이 칩 우선.** 자유 입력은 항상 가능하되 보조. 키보드 호출 최소화.
5. **라이브 미리보기**가 방송 알림처럼 보이게(가치 체감 + 온보딩).
6. **익스프레스 버튼 상시 노출** ("⚡ 바로 후원") — 결제를 막지 않는다는 원칙의 시각화.
7. **완료 화면의 감정 보상** — 컨페티/효과 재현으로 보상감, 그리고 재후원 CTA.

`prototype/index.html` 에 있다.
