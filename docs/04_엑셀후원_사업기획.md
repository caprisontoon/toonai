# 04. 사업기획 — 엑셀(크루) '시그니처 후원' 전략

> **작성: 사업기획자** · **수신: 서비스 기획자**
> **목적: 엑셀 방송 출연자에게 '시그니처'를 후원하는 도네이터 페이지로 후원 매출 극대화**
> **연계: [`01_사업기획.md`](01_사업기획.md)(일반 후원 개선)의 후속**

> ⚠️ **방향 정정 메모(중요):** 후원 페이지는 **순위판·현황·결과를 넣지 않는다.** 그것들은
> 시청자가 **방송 화면**에서 이미 본다. 페이지의 임무는 단 두 결정을 빠르게 끝내는 것 —
> **누구에게(WHO) · 어떤 시그니처로(WHICH SIGNATURE).**

---

## 1. 배경 — 엑셀 방송과 '시그니처'

**엑셀 방송**: 여러 크리에이터가 합방으로 실시간 후원 경쟁을 벌이는 포맷. 후원 매출의
절대 비중을 차지한다. 시청자는 방송 화면에서 순위·격차를 **보고**, 자기 픽에게 후원한다.

→ 그렇다면 후원 페이지가 할 일은 "정보 제공(순위)"이 아니라, **마음먹은 후원을 가장 빠르고
재미있게 집행**하는 것이다. 그 집행의 단위가 **시그니처(Signature)** 다.

**시그니처 정의:** *출연자별로 큐레이션된 대표 후원 상품.*

```
시그니처 = { 이름, 아이콘, 금액, 방송 연출(효과·음성·애니메이션) }
예) 하나비 🐰 — "달토끼 레전드 🌙" ₩50,000 : 달토끼 떡방아 풀스크린 연출 + 시그 음성
```

시청자는 **금액·효과·메시지를 따로 정하지 않는다.** "그 사람다운 시그니처" 하나를 고르면
금액·연출이 한 번에 결정된다. → **3중 결정(누구·얼마·효과)을 2탭(누구·시그니처)으로 압축.**

---

## 2. 엑셀 방송 모니터링 체계 (사업팀 운영)

페이지를 잘 만드는 것과 별개로, **어떤 방송에 누가 나오는지**와 **어떤 시그니처가 잘 팔리는지**를
상시 파악해 페이지에 반영해야 한다.

### 2.1 출연 라인업 모니터링 (페이지 준비 — 필수)
| 신호 | 채널 | 활용 |
|------|------|------|
| 엑셀 합방 편성·출연자 명단 | 방송 공지, 크리에이터 SNS | **그날 페이지의 출연자 라인업 세팅** |
| 신규 크루/게스트 합류 | 커뮤니티, 공지 | 게스트용 시그니처 사전 준비 |

### 2.2 시그니처 성과 모니터링 (큐레이션 — 매출 직결)
| 지표 | 활용 |
|------|------|
| 시그니처별 판매량·매출·전환 기여 | **잘 팔리는 시그니처 강조, 사장된 것 교체** |
| 티어별(기본/스페셜/레전드) 믹스 | 객단가 설계 점검, 신규 레전드 출시 타이밍 |
| 출연자별 시그니처 인기 편차 | 크리에이터별 시그니처 코칭/리뉴얼 |

### 2.3 라이브 옵스 (운영)
- 합방 시간대 **결제 성공률** 모니터링(마음먹은 후원이 결제 실패로 증발하면 직접 손실).
- 이상 거래·환불 패턴 감지.

> 핵심: 모니터링의 산출물은 "순위 리포트"가 아니라 **「오늘의 출연 라인업」과
> 「시그니처 큐레이션」** — 둘 다 페이지에 바로 반영된다.

---

## 3. 문제 진단 — 지금 후원하려면

엑셀 방송 중 시청자는 "○○에게 쏘자!"라고 마음먹는다. 그런데 기존 후원 페이지는:

| 마찰 | 상황 | 매출 영향 |
|------|------|----------|
| **누구인지 다시 찾기** | 합방 출연자가 페이지에 정리돼 있지 않아 검색/이동 | 이탈 |
| **결정 과부하** | 금액·효과·옵션·메시지를 매번 새로 결정 | 전환↓, 객단가 최소화 |
| **"그 사람다움" 없음** | 누구에게 쏘든 똑같은 일반 후원 | 재미·반복·고액 동기 없음 |
| **연속 후원 불편** | 여러 출연자에게 나눠 쏘려면 매번 처음부터 | 멀티 후원 기회 손실 |

> 결론: 마음은 이미 정해졌는데, **집행 단계의 결정 과부하**가 전환과 객단가를 깎는다.
> 출연자 라인업과 시그니처가 정리돼 있으면 이 마찰은 사라진다.

---

## 4. 전략 — "결정을 둘로 줄인다: 누구 + 시그니처"

```
[기존] 누구 찾기 → 금액 결정 → 효과 결정 → 메시지 → 결제   (집행 과부하)
                         ↓ 전환
[개선] ① 출연자 선택(WHO) → ② 시그니처 선택(WHICH) → 끝       (2탭 집행)
        라인업이 보임          시그니처가 금액·연출을 한 번에
```

매출 레버 매핑:

| 레버 | 시그니처 모델이 푸는 방식 |
|------|--------------------------|
| **전환율** | 결정 2개(누구·시그니처)로 압축 → 마음먹은 후원이 막힘없이 집행 |
| **객단가** | **시그니처 티어(기본/스페셜/레전드)로 가격을 상품처럼 설계.** 레전드가 고액 후원을 견인 |
| **후원 빈도** | 시그니처는 캐릭터성·수집성 → "이 사람엔 이거" 반복. 엑셀=여러 출연자 → 멀티 후원 |
| **LTV/IP** | 시그니처가 크리에이터 브랜드化. 신규 시그니처 출시 = 재방문 이벤트 |

> 핵심 통찰: **시그니처는 객단가·재미·브랜드를 동시에 설계하는 상품 단위다.**
> 금액을 묻지 말고, "그 사람다운 후원"을 고르게 하라.

## 5. 서비스팀 요구사항 (사업 → 서비스)

### ① 출연자 라인업이 첫 화면 (WHO)
- 그날 엑셀 출연자를 한눈에. 탭 한 번으로 선택, **다른 출연자로 전환도 한 번에**(멀티 후원).
- 순위·금액 현황은 **넣지 않는다**(방송이 보여줌). 누구인지 알아보게 하는 데만 집중.

### ② 시그니처가 후원의 단위 (WHICH) — 핵심
- 선택한 출연자의 **시그니처 그리드**. 각 카드 = 아이콘·이름·연출 한 줄·금액.
- 시그니처를 고르면 금액·효과가 함께 결정 → **금액/효과를 따로 묻지 않는다.**

### ③ 티어로 객단가 설계
- **기본 / 스페셜 / 레전드** 3티어. 레전드는 화려한 연출로 고액을 정당화(강매 아님).
- '인기'·'추천' 뱃지로 베스트셀러를 가볍게 안내.

### ④ 2탭 집행 + 연속 후원
- WHO→SIGNATURE→(즉시 확인)→완료. 완료 후 **바로 다음 출연자에게** 이어가기 쉽게.
- 응원 한마디는 **선택**(추천 칩 제공), 강제 입력 금지.

### ⑤ 완료 연출 = 보상
- 후원 즉시 시그니처 연출을 페이지에서도 살짝 재현(보상감). 단 과하지 않게.

### ⑥ 건전 후원 가드레일(경량)
- 오늘 누적 후원액을 확인 시점에 작게 노출, 한도 설정 링크 상시.
- 압박 카피 금지. (긴장감은 방송이 만들고, 페이지는 '집행'에 집중)

## 6. KPI

| 구분 | KPI | 방향 |
|------|-----|------|
| 1차 | 후원 전환율(페이지 진입→결제) | +20%↑ |
| 1차 | 평균 후원액(시그니처 티어 믹스) | 레전드/스페셜 비중↑ |
| 2차 | 인당 후원 출연자 수(멀티 후원) | +↑ |
| 2차 | 시그니처별 채택률·재구매율 | 큐레이션 근거 |
| 3차 | 신규 시그니처 출시 후 재방문 | LTV |
