# 06. 디자인 — '시그니처 후원' 페이지 UI 가이드 (WHO + SIGNATURE)

> **작성: 디자이너** · **입력: [`05_엑셀후원_서비스기획.md`](05_엑셀후원_서비스기획.md)**
> **산출: UI 가이드 + 동작 프로토타입 (`prototype/excel.html`)**

> ⚠️ 순위판·타이머·격차 게이지 등 **현황 UI는 디자인하지 않는다.** 화면엔
> **출연자 라인업(WHO) + 시그니처 그리드(WHICH)** 두 영역만 존재한다.

---

## 1. 디자인 목표

> *"음식 메뉴판처럼 — 누구(가게)를 고르고, 그 집 시그니처 메뉴를 고른다.
> 고르는 행위 자체가 재미있고, 두 번의 탭으로 끝난다."*

- **2탭 직관:** 출연자 탭 → 시그니처 탭 → 보내기. 군더더기 0.
- **고르는 즐거움:** 시그니처 카드는 캐릭터성 있는 '상품'. 진열이 곧 콘텐츠.
- **티어 가독:** 기본/스페셜/레전드가 한눈에 구분 → 객단가 자연 상승.
- **연속 후원:** 한 명 끝내면 다음 출연자로 매끄럽게.

## 2. 비주얼 시스템 (01~03 토큰 확장)

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--tier-basic` | `#A99FD0`(dim) | 기본 시그니처 외형 |
| `--special` | `#8B5CF6` | 스페셜 — 퍼플 보더/글로우 + `SPECIAL` 태그 |
| `--legend` | `#FBBF24` | 레전드 — 골드 보더/글로우 + `LEGEND` 리본 + 시머 |
| `--hot` | `#F472B6` | `🔥 인기` 뱃지 |
| `--ai` | `#34D399` | `🤖 추천` 뱃지 |
| 금액 타이포 | `tabular-nums`, 800 | 카드 하단 금액 |

다크+퍼플 베이스 유지. 시그니처 연출(이모지)이 화사하게 살도록 카드 배경은 차분하게.

## 3. 레이아웃 (모바일 우선)

```
┌──────────────────────────────┐
│ ◀  하나비 크루 · 시그니처 후원 │ 헤더 56px
├──────────────────────────────┤
│ 오늘 엑셀 출연 · 5명           │ 라벨
│ ●○○○○  가로 스크롤 아바타      │ 출연자 라인업 sticky (~96px)
│ 유리아 [하나비] 민트 도윤 새벽 │ 선택=보라 링+이름 강조
├──────────────────────────────┤
│ 🐰 하나비의 시그니처           │ 섹션 타이틀
│ ┌─────────┐ ┌─────────┐        │ 시그니처 그리드 (2열, 스크롤)
│ │  💗      │ │  🥕      │       │ 카드: 아이콘 / 이름 / 연출 / 금액
│ │ 심쿵 하트│ │ 당근 점프│       │
│ │ 하트 팡팡│ │ 콩콩 점프│       │
│ │ ₩2,000  │ │ ₩5,000  │        │
│ └─────────┘ └─────────┘        │
│ ┌─────────┐ ┌─────────┐ LEGEND │
│ │🐰 토끼굴 │ │🌙 달토끼 │◀리본  │
│ └─────────┘ └─────────┘        │
│ [ ✏️ 직접 금액으로 후원 ]       │ 보조(대시 카드)
└──────────────────────────────┘
   ↓ 확인 시트 / 완료 연출은 오버레이
```

- 출연자 아바타 64px 원형 + 이름. 선택 시 보라 링 + 글로우.
- 시그니처 카드 2열, 높이 ~150px. 레전드는 1열 와이드로 강조해도 좋음(프로토타입은 2열 + 리본).

## 4. 컴포넌트 명세

| 컴포넌트 | 디자인 | 상태 |
|----------|--------|------|
| **출연자 칩** | 원형 아바타(이모지)+이름 | default / **selected**(보라 링+글로우) / press |
| **빈 상태** | "출연자를 골라주세요 👆" + 아바타 살짝 펄스 | WHO 미선택 시 |
| **시그니처 카드** | 아이콘(대)·이름·연출 한 줄·금액 | 티어별 외형 / press(scale) |
| ├ 기본 | 평범한 surface | — |
| ├ 스페셜 | 퍼플 보더+은은한 글로우, `SPECIAL` 태그 | — |
| └ 레전드 | 골드 보더+글로우, `LEGEND` 리본, 시머 애니메이션 | — |
| **뱃지** | `🔥 인기`(핑크) / `🤖 추천`(민트), 카드 우상단 | 1개 이내 |
| **직접 금액 카드** | 대시 보더, 보조 위계 | — |
| **확인 시트** | 출연자+시그니처 요약 → 응원 한마디 칩(선택) → 보내기 → 오늘 누적 | slide-up |
| **완료 연출** | 시그니처 이모지 버스트 + 텍스트 + [한번더][다른출연자] | celebrate |

### 모션
| 모션 | 스펙 | 의미 |
|------|------|------|
| 출연자 전환 | 그리드 fade/slide 180ms | "다른 메뉴판" 느낌 |
| 카드 press | scale .97, 120ms | 탭 피드백 |
| 레전드 시머 | 보더 그라데이션 2.5s loop | 고티어 가치 |
| 완료 버스트 | 시그니처 이모지 파티클 + 컨페티 | **보상의 절정** |

## 5. 라이팅 가이드
- 시그니처 이름은 **캐릭터답고 짧게**(연출이 그려지게). 연출 설명은 한 줄.
- 압박 카피 금지(긴장감은 방송이 만든다). 가드레일 카피는 다정하게.
  - O: "오늘 ₩30,000 후원했어요 · 한도 설정" / X: "지금 레전드 안 쏘면 후회해요".

---

## 6. 프로토타입 (`prototype/excel.html`)
단일 HTML(의존성 0). **순위판 없음** — 순수 'WHO + SIGNATURE' 후원 picker.

- 5명 엑셀 출연 라인업(가로 스크롤) → 탭으로 선택/전환
- 출연자별 4개 시그니처(기본/스페셜/레전드 티어 + 인기/추천 뱃지)
- 시그니처 탭 → 확인 시트(응원 한마디 칩·오늘 누적) → 보내기 → **시그니처 이모지 버스트 완료 연출**
- 완료 후 [같은 분께 한 번 더]/[다른 출연자]로 **멀티 후원 루프**
- `✏️ 직접 금액` 보조 옵션 포함

```bash
open prototype/excel.html        # 또는
cd prototype && python3 -m http.server 8080   # → http://localhost:8080/excel.html
```

## 7. 디자인 결정 메모
- **순위 UI 제거:** 방송이 보여주는 정보를 페이지에서 반복하지 않는다 → 화면이 후원 '행위'에만 집중.
- **메뉴판 메타포:** 출연자=가게, 시그니처=시그니처 메뉴. 누구나 직관적으로 이해.
- **티어 외형 차등:** 가격을 묻지 않아도 레전드의 '특별함'이 보이게 → 객단가 설계의 시각화.
- **완료 후 즉시 다음 출연자 CTA:** 엑셀의 본질(여러 명에게 쏨)을 동선으로 지원.
