# 06. 디자인 — 엑셀(크루) 후원 페이지 UI 가이드

> **작성: 디자이너**
> **입력: [`05_엑셀후원_서비스기획.md`](05_엑셀후원_서비스기획.md) (디자인 전달사항 7개)**
> **산출: UI 디자인 가이드 + 동작 프로토타입 (`prototype/excel.html`)**

---

## 1. 디자인 목표

> *"엑셀표의 정보력 + 스포츠 중계의 긴장감 + 게임의 보상감.
> 행을 누르는 순간, 나는 관중이 아니라 선수가 된다."*

- **한눈 파악:** 진입 3초 안에 순위·격차·남은 시간이 읽힌다.
- **살아있는 화면:** 금액이 구르고, 행이 자리를 바꾸고, 변동이 깜빡인다.
- **명확한 위계:** 평시 정보 ↔ 역전 버튼 ↔ 마감 연출의 강도를 단계로 구분.
- **자각 있는 소비:** 누적액·한도는 항상 보이되 잔소리처럼 느껴지지 않게.

---

## 2. 비주얼 시스템 (01~03 시스템 확장)

기존 다크+퍼플 토큰을 그대로 쓰고, 엑셀 모드 전용 토큰을 추가한다.

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--gold` | `#FBBF24` | 1위 행 좌측 보더·왕관·우승 연출 |
| `--silver` | `#CBD5E1` | 2위 |
| `--bronze` | `#D97706` | 3위 |
| `--up` | `#34D399` | 순위 상승 ▲, 금액 증가 펄스 |
| `--down` | `#F87171` | 순위 하락 ▼ |
| `--danger` | `#EF4444` | 스나이핑 타임 타이머 펄스 (타이머에만, 전면 금지) |
| 숫자 타이포 | `tabular-nums` | 금액·타이머 — 카운트업 시 흔들림 방지 (필수) |

**엑셀 그리드 메타포:** 컬럼 헤더(순위/크루/후원액/변동) + 짝수 행 미세 스트라이프 +
얇은 행 구분선. "표"의 신뢰감을 주되 셀 보더를 다 치지는 않는다(답답함 방지).

## 3. 레이아웃 (모바일 우선)

```
┌──────────────────────────────┐
│ ◀  하나비 크루 · 엑셀 후원  [R3]│ 헤더 56px
│ [⏱ 14:32] [총 ₩4.45M] [👀12.4K]│ 스탯 스트립 40px — 타이머가 첫 칸(좌측 시선 시작점)
├──────────────────────────────┤
│ 순위  크루         후원액 변동 │ 그리드 헤더(uppercase, dim)
│ ░ 행 56px × 5~10 ░            │ 순위판 = 화면의 60% (스크롤)
├──────────────────────────────┤
│ 내 픽 바 (sticky, ~120px)     │ 격차+게이지+금액칩 — 엄지 영역
└──────────────────────────────┘
```

- 행 높이 56px(터치 타깃 확보), 내 픽 행은 보라 글로우 보더 + `내 픽 💜` 라벨.
- 바텀시트는 내 픽 바 위로 슬라이드 업, 뒤 배경 dim.
- 투니 토스트는 내 픽 바 바로 위에 떠서 엄지로 즉시 액션 가능.

## 4. 컴포넌트 명세

| 컴포넌트 | 핵심 디자인 | 상태 |
|----------|------------|------|
| **랭크 로우** | 메달(1~3위)/숫자 + 아바타 + 이름 + 금액(tabular) + 변동 뱃지 | 내픽/탭 프레스/금액 펄스 |
| **변동 뱃지** | `▲1` green / `▼1` red / `·` dim | 변동 후 3초 유지 |
| **격차 게이지** | 내 픽 바 내 가로 바, 내픽/1위 비율. 1위면 만땅+🛡️ | 추격/수성 |
| **마감 타이머** | 필 형태, tabular-nums | 평시 보라 → ≤30초 적색 펄스 |
| **역전 칩 ⚡** | 그라데이션+글로우, 일반 칩과 별격 | 추격: `⚡역전 ₩71,000` / 1위: `🛡️굳히기` / 완화모드: 숨김 |
| **후원 바텀시트** | 멤버 요약 → 금액 칩(+직접입력) → 응원 문구 칩 → 보내기 → 누적/한도 | 금액 선택 시 버튼 라벨 동기화 |
| **투니 토스트** | 아바타+한 줄+액션 버튼 1개, 4초 자동 닫힘 | 정보/경보(추월)/완화 |
| **결과 모달** | 시상식 — 🏆 우승자, Top3, 내 기여 리포트, 다음 라운드 CTA | 컨페티 |

### 모션 (살아있는 화면의 재료)

| 모션 | 스펙 | 의미 |
|------|------|------|
| 행 자리 교체 | FLIP, 450ms `cubic-bezier(.2,.8,.2,1)` | **경쟁의 가시화 — 이 페이지의 심장** |
| 금액 카운트업 | 450ms, tabular-nums | 돈이 "쌓이는" 감각 |
| 금액 증가 펄스 | 행 배경 600ms 플래시(green tint) | 방금 누가 쐈는지 표시 |
| 역전 순간 | 행 글로우 + 왕관 팝 + 컨페티 버스트 | 최대 보상 (서비스 전달⑥) |
| 스나이핑 타임 | 타이머만 1s 적색 펄스 | 긴장 — 화면 전체 붉힘 금지 |

## 5. 라이팅(카피) 가이드 — 긴장감과 건전성의 경계

| 상황 | O (상태 전달) | X (결제 압박) |
|------|--------------|---------------|
| 마감 임박 | "마감 30초 전이에요 ⏱" | "지금 안 보내면 집니다!" |
| 추월당함 | "유리아님이 추월했어요. 격차 ₩12,000" | "이대로 당할 거예요?" |
| 역전 제안 | "⚡ 역전 ₩71,000" (금액 정보) | "₩71,000이면 이겨요, 어서!" |
| 한도 임박 | "오늘 많이 응원했어요. 잠깐 쉬어가도 좋아요 ☕" | (한도 자체를 숨기는 것) |

이모지 1개 이내, 문장은 짧게. 투니는 해설자 톤 — 부추기지 않고 알려준다.

## 6. 프로토타입 (`prototype/excel.html`)

단일 HTML(의존성 0). **2분 데모 라운드**로 실제 운영 텐션을 압축 체험:

- 5인 크루 라이브 순위판 — 다른 팬덤의 후원이 자동 시뮬레이션되어 행 교체·카운트업 발생
- 행 탭 → 후원 시트 / 내 픽 바 원탭 금액 / **⚡ 역전 버튼**(격차+₩1,000 자동 계산)
- 추월당하면 투니 토스트 + [바로 역전], 마감 30초 전 스나이핑 타임(적색 펄스)
- 역전 성공 시 왕관+컨페티, 마감 시 결과 모달(우승+내 기여 리포트) → 다음 라운드
- 누적 후원액·한도 안내(가드레일) 데모 포함

```bash
open prototype/excel.html        # 또는
cd prototype && python3 -m http.server 8080   # → http://localhost:8080/excel.html
```

## 7. 디자인 결정 메모

- **타이머를 스탯 스트립 첫 칸에:** 좌→우 시선 시작점 = 가장 중요한 정보(남은 시간).
- **격차를 게이지+숫자 이중 표기:** 숫자는 행동(역전 금액), 게이지는 감각(얼마나 가까운가).
- **역전 칩만 글로우:** 객단가 엔진(사업 요구②)의 시각적 번역. 단 완화 모드에선 제거 —
  가드레일이 연출보다 우선한다는 위계를 디자인으로 명시.
- **적색은 타이머에만:** 긴박감은 점이면 충분. 면으로 쓰면 불안·압박이 된다.
- **결과 모달을 '시상식'으로:** 라운드의 끝을 보상으로 마감해야 다음 라운드 복귀(LTV)로 이어진다.
