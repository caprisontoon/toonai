## 1. 컨셉 — "크루 엑셀 모드(Crew Excel Mode)"

크루 후원 페이지에 **엑셀 모드**를 신설한다. 방송 화면의 엑셀표를 단순 복제하는 게 아니라,
**순위판 자체가 후원 인터페이스**가 되는 "참여형 스코어보드"다.

- **한 문장 정의:** *"스포츠 중계처럼 보고, 게임처럼 참여한다 — 행을 누르면 후원이 시작된다."*
- **투니(Tooni) 통합:** [`02_서비스기획.md`](02_서비스기획.md)의 AI 도우미를 이 페이지에선
  **'경기 해설자 + 코치'**로 활용 — 추월당하면 알려주고, 역전 금액을 계산해 제안한다.

### 설계 4원칙 (사업 요구사항의 번역)

1. **Board = Button** — 순위판이 곧 후원 진입점. 보는 화면과 내는 화면을 분리하지 않는다.
2. **Gap = Motivation** — 격차는 항상 구체적 숫자와 게이지로. 암산 금지(시스템이 계산).
3. **Deadline = Drama** — 마감 타이머 상시 노출, 마지막 구간은 연출 강화. 단 결제 압박 카피 금지.
4. **Healthy Competition** — 누적액 상시 표시, 한도/완화 모드 내장. 경쟁은 즐겁게, 소비는 자각하게.

## 3. 핵심 기능 명세

### 3.1 실시간 순위판 (요구① Board = Button)
- 멤버별 **누적 후원액·순위·변동(▲▼)** 을 1초 내 반영. 금액은 카운트업, 순위 변경은
  **행 슬라이드 교체 애니메이션**(자리가 바뀌는 게 눈에 보여야 경쟁이 체감됨).
- **행 탭 → 해당 멤버 후원 바텀시트.** 내 픽이 아닌 멤버에게도 즉시 후원 가능
  (시트 안에서 "내 픽으로 설정" 토글).
- 1~3위 메달 표기, 내 픽 행은 상시 하이라이트.

### 3.2 격차 게이지 + 역전 버튼 (요구② 객단가 엔진) ⭐
- **내 픽 바(sticky)** 에 격차를 상시 표시:
  - 추격 중: `1위까지 ₩70,000` + 추격 게이지(내 픽/1위 비율)
  - 1위: `2위와 격차 ₩50,000 · 수성 중 🛡️`
- **⚡ 역전 버튼**: `격차 + ₩1,000`(천원 올림)을 원탭 후원 금액으로 제안.
  1위일 땐 **🛡️ 굳히기 버튼**(격차 벌리기 추천액)으로 전환.
- 역전 성공 시 즉시 강한 보상 연출(왕관·컨페티) — "내 돈이 순위를 바꿨다"는 효능감이
  이 페이지의 핵심 보상.

### 3.3 마감 타이머 + 스나이핑 타임 (요구③ Deadline = Drama)
- 타이머 상시 노출. **마감 30초(운영값: N분) 전 '스나이핑 타임' 진입** — 타이머 적색 펄스,
  투니 1회 안내. *카피는 상태 전달까지만*: "마감 30초 전이에요" (O) / "지금 안 보내면 져요" (X).
- 마감 순간 서버 타임스탬프 기준 정산(클라 시계 불신). 마감 직전 결제는 **충전+후원 결합**으로
  한 번에 — 잔액 부족으로 마감을 놓치는 일 방지.

### 3.4 원탭 반복 후원 + 콤보 (요구④)
- 내 픽 바의 금액 칩 = **사전 동의 후 원탭 즉시 결제**(설정에서 켜는 옵션, 기본은 시트 확인).
- 짧은 간격 연속 후원 시 **콤보 피드백**(x2, x3 토스트) — 반복 후원의 미시 보상.
  콤보는 연출일 뿐 금전 혜택 아님(사행성 경계).

### 3.5 서포터 랭킹 · 기여 리포트 (요구⑤)
- 첫 후원 후 내 픽 바에 `오늘 내 기여 ₩30,000 · 하나비 서포터 7위` 표시.
- 라운드 종료 모달에 **내 기여 리포트**(기여액·서포터 순위·역전 기여 순간) → 다음 라운드 복귀 동기.

### 3.6 투니 스마트 알림 (AI 통합)
- **추월 알림**: 내 픽이 추월당하면 토스트 — `🚨 유리아님이 추월! 격차 ₩12,000` + `[⚡ 바로 역전]`
  액션 버튼(시트를 역전 금액 프리셋으로 오픈).
- **빈도 제한**: 동일 유형 알림 10초 쿨다운, 분당 최대 N회 — 알림 피로는 신뢰를 깎는다.
- 메시지 작성 도우미(02 기획)는 시트 안 **응원 문구 추천 칩**으로 경량 재사용.

### 3.7 건전 후원 가드레일 (요구⑥)
- 시트 하단에 **오늘 누적 후원액 + 한도 설정 링크** 상시 표시.
- 일일 한도 임박/도달 시 **완화 모드**: 역전·스나이핑 등 어그로 요소 숨김, 휴식 안내 카피,
  투니가 부드럽게 1회 안내. 한도 해제는 쿨다운 후 본인 재설정만 가능.

## 4. 대표 시나리오 — "마감 5분 전 역전극"

```
상황: 하나비 크루 라운드3. 내 픽 '하나비' 2위, 1위 '유리아'와 격차 ₩70,000. 마감 5:00 전.

① 나, 페이지 진입 → 순위판에서 상황 즉시 파악 (방송 화면 안 봐도 됨)
② 내 픽 바: "1위까지 ₩70,000" + [₩10,000][₩30,000][⚡역전 ₩71,000]
③ [₩30,000] 탭 → 시트에서 응원 문구 칩 "스나이핑 들어갑니다 😎" 선택 → 보내기
   → 순위판 금액 카운트업, 격차 ₩40,000으로 갱신, 토스트 "격차가 ₩40,000으로 줄었어요!"
④ (1분 뒤) 유리아 팬덤 맞후원 → 투니 토스트 "🚨 격차 ₩55,000으로 벌어졌어요 [⚡ 바로 역전]"
⑤ 마감 0:30 → 스나이핑 타임 진입(타이머 적색) — "마감 30초 전이에요"
⑥ [⚡ 역전 ₩56,000] 탭 → 충전 잔액 부족 → 충전+후원 결합 결제 한 번에 완료
   → 🚀 행 슬라이드 교체! 하나비 1위 등극, 왕관+컨페티
⑦ 마감 0:00 → 결과 모달: "🏆 하나비 우승!" + 내 기여 리포트(₩86,000 · 서포터 3위 ·
   '역전 결정타' 뱃지) → [다음 라운드 알림 받기]
```

## 6. 측정 설계

- **퍼널 이벤트:** `excel_open → row_tap/pickbar_tap → sheet_open → amount_select(역전 여부 태깅)
  → pay_success` + `overtake_toast_shown/clicked`, `snipe_window_pay`, `round_result_view`, `next_round_optin`
- **A/B:** ① 역전 버튼 유/무 (객단가 엔진 검증 — 핵심 실험) ② 추월 알림 유/무 ③ 콤보 연출 유/무
- **가드레일 지표:** 한도 설정률, 완화 모드 진입률, 민원/환불률, 알림 끔 비율 — 악화 시 연출 강도 자동 하향.

## 7. 디자인팀 전달 사항 (서비스 → 디자인)

1. **순위판이 히어로.** 화면의 60%를 순위판에. "엑셀 그리드"의 정보감(컬럼 헤더·행 스트라이프)을
   세련되게 — 스포츠 스코어보드 느낌으로.
2. **변동이 보여야 한다.** 행 교체 슬라이드, 금액 카운트업, ▲▼ 변동 뱃지 — 정적이면 죽은 페이지.
3. **내 픽 바는 sticky.** 격차 텍스트·게이지·원탭 금액·역전 버튼이 엄지 영역에 상시.
4. **역전 버튼은 별격으로.** 일반 금액 칩과 시각 위계 분리(⚡·글로우) — 단 한도 완화 모드에선 숨김.
5. **마감 연출 2단계.** 평시 → 스나이핑 타임(적색 펄스). 화면 전체를 붉히지 말 것(불안 유발 금지).
6. **역전 순간 = 최대 보상.** 왕관·컨페티·행 하이라이트. 라운드 결과 모달은 '시상식'처럼.
7. **가드레일의 디자인.** 누적액·한도 링크는 작지만 항상 보이게. 완화 모드 카피는 다정하게.
