> 그건 방송 화면의 몫이다. **이 페이지엔 오직 '누구 + 시그니처' 선택만 있다.**

## 1. 컨셉 — "2탭이면 끝나는 시그니처 후원"

엑셀 방송을 보던 시청자가 "○○에게 쏘자!"라고 마음먹은 순간, 페이지는 그 마음을
**가장 빠르고 재미있게 집행**한다. 결정은 단 두 개.

```
   ① 누구에게 (WHO)            ② 어떤 시그니처로 (WHICH SIGNATURE)
   ─ 출연자 라인업에서 탭 ─►   ─ 그 사람의 시그니처 그리드에서 탭 ─►  완료
```

**시그니처(Signature):** 출연자별 대표 후원 상품. 하나를 고르면 **금액·연출이 함께 결정**된다.

```
시그니처 = { id, 아이콘, 이름, 금액, 티어, 방송 연출(효과/음성), (추천/인기 뱃지) }
예) 하나비 🐰
   · 심쿵 하트 💗   ₩2,000   [기본]   하트가 팡팡
   · 토끼굴 파티 🐰 ₩10,000  [스페셜] 토끼 우르르 + 시그 음성
   · 달토끼 레전드 🌙 ₩50,000 [레전드] 달토끼 떡방아 풀스크린
```

### 설계 4원칙
1. **Two Decisions Only** — 누구·시그니처. 그 외(금액·효과·메시지)는 묻지 않거나 선택사항.
2. **No Scoreboard Here** — 순위·현황·결과는 방송이 보여준다. 페이지는 '집행'에만 집중.
3. **Signature = Product** — 시그니처는 캐릭터성 있는 상품. 티어로 객단가를 설계.
4. **Easy Multi-Donate** — 한 명 끝내면 다음 출연자로 한 번에. 엑셀은 여러 명에게 쏜다.

## 2. 화면 구조 (IA) — 한 화면, 두 영역

```
┌──────────────────────────────┐
│ ◀  하나비 크루 · 시그니처 후원 │  헤더
├──────────────────────────────┤
│ 오늘 엑셀 출연 (5명)          │  ① WHO — 출연자 라인업(가로 스크롤, sticky)
│  (🦊)(🐰•)(🐱)(🐺)(🦉)        │     아바타 탭 = 선택 / 다른 사람 탭 = 전환
│   유리아 하나비 민트 도윤 새벽 │     ← 선택된 사람만 보라 링
├──────────────────────────────┤
│ 🐰 하나비의 시그니처          │  ② WHICH — 선택한 사람의 시그니처 그리드
│ ┌────────┐ ┌────────┐         │
│ │💗 심쿵  │ │🥕 당근  │        │     카드 = 아이콘·이름·연출 한 줄·금액
│ │₩2,000  │ │₩5,000  │         │     티어별 외형(기본/스페셜/레전드)
│ ├────────┤ ├────────┤         │
│ │🐰 토끼굴│ │🌙레전드 │ LEGEND │
│ │₩10,000 │ │₩50,000 │        │
│ └────────┘ └────────┘         │
│ [✏️ 직접 금액으로 후원]         │     (보조 옵션)
└──────────────────────────────┘
  ↓ 시그니처 탭
  [확인 시트] 출연자·시그니처·금액 + 응원 한마디(선택) + 보내기 + (오늘 누적)
  ↓ 보내기
  [완료 연출] 시그니처 연출 재현 + "○○님께 △△ 전달!" → [한 번 더] [다른 출연자]
```

> 선택 전(WHO 미선택)에는 본문에 *"후원할 출연자를 골라주세요 👆"* 빈 상태를 보여
> **WHO가 1번 결정임을 명확히** 한다.

## 3. 시그니처 모델 (큐레이션 규칙)

| 티어 | 가격대(예) | 연출 강도 | 역할 |
|------|-----------|----------|------|
| **기본** | ₩1,000~5,000 | 가벼운 효과 | 진입·반복 후원 |
| **스페셜** | ₩10,000~30,000 | 중간 연출 + 음성 | 주력 객단가 |
| **레전드** | ₩50,000+ | 풀스크린 연출 | 고액 견인(축하·결정타) |

- 출연자마다 **3~5개** 시그니처. 페르소나(캐릭터)에 맞춘 네이밍/연출이 핵심 재미.
- **뱃지:** `🔥 인기`(판매 데이터), `🤖 추천`(상황·관계 기반 경량 추천) — 1인당 1개 이내.
- 큐레이션은 사업팀 시그니처 성과 모니터링([`04`](04_엑셀후원_사업기획.md) 2.2)과 연동.

## 4. 핵심 기능 명세

### 4.1 출연자 라인업 (WHO) — 요구①
- 그날 엑셀 출연자 리스트(서버 세팅). 아바타+이름. 가로 스크롤, 상단 sticky.
- 탭으로 선택, 다른 아바타 탭으로 **즉시 전환**(선택 상태 1명). 순위/금액 표기 없음.
- 출연자 多일 때: 정렬(편성순/즐겨찾기), 검색은 6명 초과 시 노출.

### 4.2 시그니처 그리드 (WHICH) — 요구②③
- 선택한 출연자의 시그니처 카드 그리드. 카드 탭 → 확인 시트.
- 티어별 외형 구분, 인기/추천 뱃지. **금액·효과를 따로 묻지 않음**(시그니처에 내장).
- 보조: `✏️ 직접 금액` — 시그니처가 아닌 자유 금액(같은 확인 시트, 금액 입력만 활성).

### 4.3 확인 시트 — 요구④
- 출연자 + 시그니처 + 금액 요약. **응원 한마디(선택)** — 추천 칩 3~4개 또는 미입력.
- `보내기` 원탭 결제(저장수단). 잔액 부족 시 충전+후원 결합. 하단 **오늘 누적**(가드레일).

### 4.4 완료 연출 — 요구⑤
- 시그니처 아이콘 버스트 + "○○님께 '△△' 전달!" + 연출 한 줄.
- 다음 행동: **[💜 같은 분께 한 번 더]** / **[🔄 다른 출연자]** → 멀티 후원 루프.

### 4.5 AI 경량 추천 (투니 통합)
- 시그니처 그리드에 `🤖 추천` 뱃지(예: 관계/상황 기반 1개). 강요·챗봇 없음 — **거드는 수준**.

### 4.6 건전 후원 가드레일 — 요구⑥
- 확인 시트에 오늘 누적액 노출, 한도 설정 링크. 한도 임박 시 다정한 1회 안내. 압박 카피 금지.

## 5. 대표 시나리오 — "합방에서 두 명에게"

```
① 시청자, 방송에서 하나비가 1위 위태로운 걸 보고 "쏴야지!" → 페이지 진입
② 출연자 라인업에서 [🐰 하나비] 탭
③ 하나비 시그니처 그리드 → [🐰 토끼굴 파티 ₩10,000 · 🔥인기] 탭
④ 확인 시트: 응원 한마디 "토끼단 화이팅 🐰" 칩 선택 → [보내기]
   → 완료 연출(토끼 우르르) "하나비님께 '토끼굴 파티' 전달!"
⑤ [🔄 다른 출연자] → [🐺 도윤] 탭 → [🌙 달빛 질주 ₩10,000] → 보내기 → 완료
   (마음먹은 두 명에게 30초 안에 멀티 후원 완료)
```

## 6. 측정 설계
- **퍼널:** `open → person_select → signature_view → signature_tap → confirm → pay_success`
  + `multi_donate(연속)`, `custom_amount_used`, `badge_signature_tap(인기/추천)`.
- **A/B:** ① 시그니처 모델 vs 기존 금액 폼(전환·객단가) ② 티어 3종 vs 2종 ③ 추천 뱃지 유/무.
- **가드레일 지표:** 한도 설정률, 민원/환불률, 평균 완료 시간.

## 7. 디자인팀 전달 사항 (서비스 → 디자인)
1. **메뉴판 메타포.** 시그니처 그리드는 "고르는 즐거움"이 있는 상품 진열처럼.
2. **WHO는 항상 보이게.** 출연자 라인업 sticky — 다른 사람으로 전환이 한 번에.
3. **티어를 한눈에.** 기본/스페셜/레전드를 색·뱃지·리본으로 즉시 구분.
4. **2탭 동선.** 시그니처 탭 → 확인 시트 → 보내기. 키보드 호출 최소화(한마디는 칩).
5. **완료 연출 = 보상.** 시그니처 아이콘 버스트, 그리고 곧장 다음 출연자로 이어지는 CTA.
6. **순위·현황 UI 없음.** 숫자 경쟁 요소를 페이지에 넣지 말 것(방송의 몫).
