# 03. 디자인 — AI 대화형 후원 UI 가이드

> **작성: 디자이너**
> **입력: [`02_서비스기획.md`](02_서비스기획.md) (대화 플로우 · 기능 명세 · 디자인 전달사항 7개)**
> **산출: UI 디자인 가이드 + 클릭 가능한 프로토타입 (`prototype/index.html`)**

---

## 1. 디자인 목표

> *"폼처럼 보이지 않게. 친구와 대화하듯, 30초 안에 마음을 전한 느낌이 들게."*

- **직관성:** 다음 할 일이 화면에 단 하나로 보인다(퀵리플라이 칩 우선).
- **대화감:** 진짜 메신저처럼 — 말풍선, 타이핑 인디케이터, 순차 등장.
- **신뢰감:** 결제 직전 요약 카드로 "내가 뭘 보내는지" 명확히.
- **보상감:** 완료 시 컨페티+효과 재현으로 "전달됐다"는 정서적 만족.

---

## 2. 비주얼 시스템

### 컬러 (투네이션 무드 — 퍼플/바이올렛 그라데이션)
| 토큰 | 값 | 용도 |
|------|-----|------|
| `--brand-700` | `#6D28D9` | 핵심 강조, 그라데이션 시작 |
| `--brand-500` | `#8B5CF6` | 버튼·링크 기본 |
| `--brand-300` | `#C4B5FD` | 보조·호버 |
| `--accent`    | `#F472B6` | 하이라이트(핑크), 컨페티 |
| `--bg`        | `#0F0B1E` | 앱 배경(다크) |
| `--surface`   | `#1B1430` | 카드·말풍선(투니) |
| `--surface-2` | `#272042` | 입력바·칩 |
| `--user-bub`  | `#7C3AED` | 사용자 말풍선 |
| `--text`      | `#F5F3FF` | 본문 |
| `--text-dim`  | `#A99FD0` | 보조 텍스트 |

> 다크 배경 + 퍼플 그라데이션 = 방송 오버레이/야간 시청 맥락에 어울리고, 효과·컨페티가
> 화사하게 살아난다.

### 타이포
- 한글 우선 시스템 폰트 스택(Pretendard 우선) — `Pretendard, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`
- 본문 15px / 칩·캡션 13px / 금액 강조 20~22px Bold.

### 모양·간격
- 말풍선/카드 radius **18px**(사용자 말풍선은 꼬리쪽 6px), 칩 **999px(pill)**.
- 그림자: 카드 `0 8px 24px rgba(0,0,0,.35)`. 살짝 떠 보이게.
- 기본 간격 8px 그리드. 말풍선 좌우 패딩 14px / 세로 10px.

### 모션
- 말풍선 등장: `translateY(8px)+fade 240ms ease-out`, 메시지 간 120ms 스태거.
- 타이핑 인디케이터: 점 3개 bounce(투니가 '생각 중').
- 효과 미리보기: 알림 카드 scale-in + 반짝임.
- 완료: 컨페티 버스트 + 체크 팝.

## 3. 레이아웃 (모바일 우선)

```
┌──────────────────────────────┐  ← 휴대폰 프레임(데스크톱은 목업)
│ ◀  투니 · 하나비에게 후원   ⚡ │  헤더: 뒤로 / 타이틀 / ⚡바로후원
├──────────────────────────────┤
│  🤖 안녕하세요! …             │  투니 말풍선(좌)
│       [🎉][💪][😂][✍️]        │  퀵리플라이 칩
│                               │
│              축하해요  🙋     │  사용자 말풍선(우)
│  🤖 ┌ 금액 카드 ───────────┐  │  인라인 카드(말풍선 안)
│     │ 1k 5k [10k] 50k  ✏️ │  │
│     └─────────────────────┘  │
│        … (스크롤) …           │
├──────────────────────────────┤
│  [＋] 메시지 입력…       [↑]  │  입력바(칩 우선, 자유입력 보조)
└──────────────────────────────┘
   안전영역(엄지 도달) = 하단 1/3
```

- **핵심 액션은 하단 1/3**(엄지 도달). 칩과 주요 버튼을 아래에 배치.
- 새 말풍선 등장 시 자동 하단 스크롤. 카드도 채팅 흐름 안에서 등장.

## 4. 컴포넌트 명세

| 컴포넌트 | 설명 | 상태 |
|----------|------|------|
| **투니 말풍선** | 아바타+말풍선(좌), radius 18 | 등장 애니메이션 |
| **사용자 말풍선** | 퍼플 채움(우) | — |
| **타이핑 인디케이터** | 점 3개 bounce | 투니 응답 전 0.6~1s |
| **퀵리플라이 칩** | pill, 탭 시 사용자 말풍선으로 전환 | default/hover/selected |
| **금액 카드** | 칩 4개+직접입력, '인기' 뱃지 | selected 강조, 효과 잠금 힌트 |
| **효과 미리보기 카드** | 방송 알림 재현(애니메이션) | play on view |
| **메시지 초안 카드** | 톤 라벨(감동/유쾌/담백) 3개 | select→편집 가능 |
| **요약 카드** | 대상·금액·효과·메시지·결제수단 + 보내기 | confirm |
| **완료 화면** | 컨페티+체크+재후원 CTA | celebrate |
| **⚡바로후원** | 헤더 상시 노출, 익스프레스 진입 | always |

### 상태 디자인
- **칩 selected:** 퍼플 채움 + 체크. **disabled:** 40% opacity.
- **금액 '인기' 앵커:** 글로우 보더로 시선 유도(강매 아닌 안내).
- **로딩/AI 생성중:** 타이핑 인디케이터 재사용(일관성).
- **에러(결제 실패):** 인라인 토스트 + "다시 시도" 칩, 맥락 유지.

## 5. 접근성 & 라이팅

- **명도 대비** 본문 텍스트 4.5:1 이상. 칩 터치 타깃 ≥ 44px.
- **자유 입력 항상 가능** — 칩은 보조. 스크린리더용 라벨 제공.
- **마이크로카피 톤:** 다정하고 짧게. 이모지는 강조용 1~2개. 강요·압박 표현 금지.
  - 좋은 예: "부담 없이 골라보세요 👇" / 나쁜 예: "지금 후원하지 않으면…".

## 6. 프로토타입 (`prototype/index.html`)

위 가이드를 그대로 구현한 **단일 HTML 파일**(설치 불필요, 의존성 0).

- 5장 대표 스크립트(S0→S7)를 **클릭으로 진행**하는 상태머신.
- 타이핑 인디케이터, 금액 카드, 효과 라이브 미리보기, 메시지 톤별 초안,
  요약 카드, 완료 컨페티까지 모두 동작.
- "다시 시작" / "⚡ 바로 후원" 포함.

실행:
```bash
open prototype/index.html        # 또는
cd prototype && python3 -m http.server 8080   # → http://localhost:8080
```

> 데스크톱에서는 휴대폰 목업 안에, 모바일에서는 전체 화면으로 렌더링된다.

## 7. 디자인 결정 메모 (왜 이렇게 했나)

- **다크 + 퍼플:** 방송/야간 맥락 + 효과·컨페티 가독. 투네이션 무드 계승.
- **칩 우선, 키보드 최소화:** "30초 완주"(사업 요구①)의 핵심. 입력 마찰 제거.
- **카드를 말풍선 안에:** 폼처럼 안 보이게 — '대화 속 선택'으로 느끼게.
- **라이브 미리보기:** 신규 온보딩(요구④)과 효과 업셀(요구②)을 한 컴포넌트로 해결.
- **완료 컨페티:** 감정 보상 루프(요구⑤)의 시각적 절정 → 재후원 CTA로 연결.
